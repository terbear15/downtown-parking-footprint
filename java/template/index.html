How much of downtown is parking?

Pick a city, or zoom into any downtown, to see the parcels taken up by surface parking. Lots shown are mapped in OpenStreetMap today; model predictions come next.

About this demo

Orange shapes are surface lots tagged amenity=parking in OpenStreetMap, downloaded {{DATA_DATE}}. OSM misses some lots, so these areas are a lower bound, not a final result.

Each city uses a rough downtown box, not an official boundary. These lots will be replaced by predictions from a U-Net trained on NAIP aerial imagery.

Real-time occupancy (whether a lot is empty) cannot be read from aerial imagery or OSM, so it is not shown.
